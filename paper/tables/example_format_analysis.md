# 논문 양식 분석표

## [양식 1] manuscript1.txt
- 파일명: `manuscript1.txt`
- 요구 분량: 원문 예시는 약 6개 본문 장과 참고문헌, 저자소개를 포함. 명시적 페이지 수 제한은 텍스트에서 직접 확인되지 않음
- 제목 형식: 영문 제목을 먼저 배치하고, 이후 국문 제목을 별도로 제시
- 저자 표기 방식: 영문 저자명과 소속을 먼저 표기한 뒤, 국문 저자명과 소속을 별도로 표기. 교신저자 정보와 투고/수정/게재확정일을 포함
- 초록 형식: 영문 `ABSTRACT`를 먼저 작성하고, 이어 국문 `요약`을 작성
- 키워드 형식: 영문 `Keywords`, 국문 `키워드`를 모두 작성
- 본문 섹션 구조: `1. 서론`, `2. 관련 연구`, `3. 네트워크 모델`, `4. ...`, `5. 성능 평가`, `6. 결론` 순서. 연구 내용에 따라 중간 장 제목은 변경 가능
- 그림 번호 표기 방식: 본문에서 그림을 번호로 참조하는 일반 학술논문 형식. 원문 세부 표기는 최종 원문 대조 필요
- 표 번호 표기 방식: 본문에서 표를 번호로 참조하는 일반 학술논문 형식. 원문 세부 표기는 최종 원문 대조 필요
- 수식 표기 방식: 필요한 경우 본문 중 수식을 별도 줄로 배치하고 번호를 붙이는 형식으로 보임. 세부 표기는 최종 원문 대조 필요
- 참고문헌 형식: `References` 제목 아래 번호형 참고문헌 `[1]`, `[2]` 형식 사용. 저자, 논문명, 학술지/학회명, 권·호, 페이지, 연도 순으로 작성
- 글꼴/여백/단 구성: 텍스트 추출본에서는 확인 불가. 원본 양식 파일 또는 PDF/한글 양식 확인 필요
- 기타 유의사항: 심사는 무기명으로 진행되므로 논문 투고/심사 시 저자정보와 연구비 지원 문구를 모두 삭제하라는 주의문이 포함됨

## [양식 2] manuscript2.txt
- 파일명: `manuscript2.txt`
- 요구 분량: 원문 예시는 약 6개 본문 장과 참고문헌, 저자소개를 포함. 명시적 페이지 수 제한은 텍스트에서 직접 확인되지 않음
- 제목 형식: 영문 제목, 영문 저자, 영문 초록을 먼저 배치한 뒤 국문 제목과 국문 저자·요약을 배치
- 저자 표기 방식: 영문 저자명과 국문 저자명을 모두 제공. 투고일, 수정일, 게재확정일, 교신저자와 소속 정보를 포함
- 초록 형식: 영문 `ABSTRACT`와 국문 `요약`을 모두 작성
- 키워드 형식: 영문 `Keywords`, 국문 `키워드`를 모두 작성
- 본문 섹션 구조: `1. 서론`, `2. 관련 연구`, `3. ...`, `4. ...`, `5. 성능 평가`, `6. 결론`의 논문 구조. 성능평가 장이 포함됨
- 그림 번호 표기 방식: 본문 내 그림 번호 참조 형식 사용. 세부 캡션 표기는 최종 원문 대조 필요
- 표 번호 표기 방식: 본문 내 표 번호 참조 형식 사용. 세부 캡션 표기는 최종 원문 대조 필요
- 수식 표기 방식: 필요한 경우 수식과 알고리즘 설명을 본문에 배치하는 일반 논문 형식. 세부 표기는 최종 원문 대조 필요
- 참고문헌 형식: `References` 제목 아래 번호형 `[1]` 형식 사용. 논문명은 따옴표로 표기하고, 학술지/학회명, 권·호, 페이지, 연도 등을 포함. 인터넷 자료는 `[Internet]`과 URL로 표기
- 글꼴/여백/단 구성: 텍스트 추출본에서는 확인 불가. 원본 편집 양식 대조 필요
- 기타 유의사항: 양식 1과 동일하게 무기명 심사 제출 시 저자정보와 연구비 지원문구 삭제 안내가 포함됨

## 공통 형식 정리
- 영문 제목, 영문 저자, 영문 초록, 영문 키워드를 먼저 제시하고, 국문 제목, 국문 저자, 국문 요약, 국문 키워드를 이어서 제시한다.
- 본문은 번호형 장 구조를 사용한다.
- 기본 흐름은 `서론 → 관련 연구 → 제안 모델/시뮬레이터 설계 → 실험/성능 평가 → 결론`이다.
- 참고문헌은 번호형 `[n]` 형식을 사용한다.
- 논문 투고 심사용 파일에서는 저자정보와 연구비 지원문구를 삭제해야 한다.

## 본 프로젝트 적용안
- 제목 후보:
  - 영문: `Implementation of an eVTOL Mobility Model Simulator and Collision Avoidance Performance Analysis`
  - 국문: `eVTOL 이동성 모델 시뮬레이터 구현 및 충돌 회피 성능 분석`
- 본문 기본 구조:
  1. 서론
  2. 관련 연구
  3. eVTOL 이동성 모델 시뮬레이터 설계
  4. 실험 설계
  5. 성능 평가
  6. 결론
- 참고문헌 형식: examples의 번호형 `[n]` 형식을 우선 적용한다.

## 확인 필요
- 글꼴, 여백, 단 구성, 그림/표 캡션의 정확한 위치와 문장부호는 텍스트 추출본만으로는 확정할 수 없다. 최종 논문 편집 단계에서 원본 양식 또는 투고 규정 파일을 직접 대조해야 한다.
