# eVTOL 이동성 모델 시뮬레이터 설계안

## 1. 설계 목표
본 시뮬레이터는 도심 격자 환경에서 eVTOL의 이륙, 상승, 순항, 건물 회피, 다중 기체 간 충돌 회피, 하강, 착륙 과정을 단순화하여 구현하는 경량 Python 기반 실험 도구를 목표로 한다.

본 연구의 핵심은 실제 UAM 운항 전체를 정밀 재현하는 것이 아니라, 학부생 수준에서 구현 가능한 이동성 모델을 만들고, 건물 회피와 비행체 간 시공간 충돌 회피 전략의 상대적 효과를 비교하는 것이다.

## 2. 문헌 기반 설계 근거
- K-UAM 기술로드맵은 UAM 운용고도 300-600 m를 제시한다. 따라서 기본 순항고도 범위는 300-600 m로 설정한다.
- K-UAM 기술로드맵은 PSU의 항로 모니터링, 항공기간 분리관리, 악기상 정보 반영, 버티포트 가용성 확인을 교통관리 기능으로 설명한다. 따라서 본 시뮬레이터의 스케줄러는 PSU 기능을 단순화한 모델로 둔다.
- 다중 UAV 4D 경로 최적화 연구는 출발 지연, 속도 조정, 경로 재계획이 충돌 해결 전략으로 사용될 수 있음을 보인다.
- 국내 다중 UAV 무충돌 비행계획 연구는 우선순위 기반 출발 지연 방식이 학부생 수준 구현에 적합한 단순 충돌 회피 전략임을 보여준다.
- UAM-CAS 시뮬레이션 연구는 충돌 횟수뿐 아니라 CPA, 지연시간, 회피기동이 평가 지표가 될 수 있음을 제시한다.
- 도심 다중 UAV 회피 연구는 건물 충돌과 비행체 간 충돌을 별도로 탐지하고, 회피 성공률·추가 비행거리·계산시간으로 성능을 평가할 수 있음을 제시한다.

## 3. 개발 스택
- Python
- NumPy: 좌표, 거리, 속도, 경로 계산
- Pandas: 결과 CSV 저장 및 요약
- Matplotlib: 2D 맵, 경로, 충돌 그래프 PNG 생성

## 5. 도시 맵 모델
### 5.1 맵 구조
- 2D 평면 격자 도시를 생성한다.
- 전체 맵은 `width × height` 크기의 직사각형이다.
- `grid_size` 간격으로 도로 격자를 생성한다.
- 도로 외 영역에 건물을 랜덤 배치한다.
- 각 건물은 `x`, `y`, `width`, `depth`, `height` 속성을 가진 직육면체로 모델링한다.

### 5.2 건물 생성
- 건물 위치는 도로 격자와 겹치지 않도록 배치한다.
- 건물 밀도는 `building_density`로 조정한다.
- 건물 높이 범위는 사용자가 설정한다.
- 건물 높이값은 문헌 직접 근거가 부족하므로, 논문에서는 사용자 승인 가정값으로 처리해야 한다.

### 5.3 버티포트 생성
- 기본 방식은 건물 옥상 또는 지정 좌표에 버티포트를 배치한다.
- 옵션:
  - 랜덤 배치
  - 건물 옥상 배치
  - 격자 중심 배치
  - 사용자 좌표 입력
- K-UAM 로드맵과 수도권 네트워크 연구를 근거로 4/8/20개 같은 단계별 시나리오를 검토할 수 있으나, 실제 실험값은 사용자 컨펌이 필요하다.

## 6. eVTOL 이동성 모델
각 eVTOL은 다음 상태를 가진다.
- `id`
- 현재 위치 `(x, y, z)`
- 출발지
- 목적지
- 목표 순항고도
- 속도
- 수직 속도
- 상태: `waiting`, `takeoff`, `climb`, `cruise`, `avoid_building`, `avoid_aircraft`, `descend`, `landed`, `failed`
- 경로 waypoints
- 출발 시간
- 도착 시간
- 지연 시간
- 건물 회피 횟수
- 비행체 회피 횟수

이동 단계는 다음과 같다.
1. 출발지 선정
2. 목적지 선정
3. 이륙
4. 상승
5. 순항고도 도달
6. 목적지 방향 직선 이동
7. 건물 충돌 가능성 탐지
8. 건물 회피 경로 생성
9. 다른 비행체와 시공간 충돌 가능성 탐지
10. 고도 변경, 경로 변경, 출발 지연, 속도 조정 중 하나를 적용
11. 목적지 상공 도달
12. 하강
13. 착륙

## 7. 고도 모델
- 기본 순항고도 범위: 300-600 m
- 출처: K-UAM 기술로드맵 pp. 206-207
- 고도 레이어 간격: 50 m 후보
- 고도 레이어 간격은 문헌 직접 근거가 부족하므로 사용자 승인 가정값으로 처리한다.
- 건물 회피 시 건물 높이에 안전 여유고도를 더한 값보다 낮게 통과하면 충돌 위험으로 판정한다.

## 8. 속도 모델
속도는 문헌에서 여러 후보가 확인된다.
- K-UAM 기술로드맵 단계별 순항속도: 150/240/300 km/h
- UAM-CAS 연구의 예상 UAM 순항속도: 110-322 km/h
- Yang & Wei 연구의 ownship 속도: 60 m/s, intruder 50-80 m/s
- 제주 UAM 경로 연구의 기체 사례: Joby S4 322 km/h, Lilium Jet 280 km/h

본 프로젝트에서는 경량 시뮬레이터의 안정성과 실험 가독성을 고려해 속도 시나리오를 `저속/중속/고속`으로 나누는 방식을 제안한다. 최종값은 사용자 컨펌 후 확정한다.

## 9. 건물 회피 모델
### 9.1 기본 판정
- 출발지와 목적지를 잇는 2D 선분이 건물 footprint와 교차하는지 확인한다.
- 해당 건물의 높이와 eVTOL의 현재 고도 또는 순항고도를 비교한다.
- 순항고도 또는 회피고도가 `건물 높이 + 안전 여유고도`보다 낮으면 건물 충돌 위험으로 판정한다.

### 9.2 회피 방식
초기 구현은 다음 중 단순한 방식부터 적용한다.
- 수평 우회: 건물 bounding box 주변에 waypoint를 추가한다.
- 고도 회피: 허용 고도 범위 내에서 상위 고도 레이어로 이동한다.
- 혼합 회피: 먼저 고도 회피 가능성을 검토하고, 불가능하면 수평 우회한다.

학부생 구현 난이도와 논문 설명 가능성을 고려해, 초기 버전은 수평 우회 또는 고도 레이어 변경 중심으로 구현한다.

## 10. 비행체 간 충돌 회피 모델
### 10.1 충돌 위험 탐지
두 eVTOL의 경로점 또는 시간별 위치를 비교해 다음 조건을 확인한다.
- 수평거리 `safety_distance_xy` 이하
- 수직거리 `safety_distance_z` 이하
- 시간 차이 `time_separation` 이하

### 10.2 회피 방식
우선순위 기반 단순 정책을 적용한다.
1. 먼저 출발한 기체 우선
2. 목적지까지 남은 거리가 짧은 기체 우선
3. ID가 낮은 기체 우선

우선순위가 낮은 기체는 다음 중 하나를 수행한다.
- 출발 시간 지연
- 고도 레이어 변경
- 속도 감소
- waypoint 우회

초기 구현에서는 출발 시간 지연과 고도 레이어 변경을 우선 적용한다.

## 12. 날씨·풍속 모델
초기 구현에서는 기능을 옵션으로 두되, 기본 논문 실험에서는 단순화하거나 제외하는 것을 제안한다.

설정 후보:
- `clear`: 영향 없음
- `windy`: 속도 보정
- `rainy`: 속도 감소 및 안전거리 증가
- `low_visibility`: 안전거리 증가

근거:
- 제주 UAM 경로 연구는 풍속을 UAM 경로 선정 비용으로 반영하였다.
- 단, 본 프로젝트의 핵심은 이동성 모델과 충돌 회피 비교이므로 날씨는 기본 모델보다 확장 기능으로 두는 것이 안전하다.

## 16. 논문에서의 한계 명시
- 본 시뮬레이터는 실제 eVTOL 동역학 전체를 반영하지 않는다.
- 센서 오차, 통신 지연, 실제 항공관제 절차는 단순화한다.
- 건물 높이, 안전거리, 수직속도 등 일부 값은 문헌에서 직접 확인되지 않으면 사용자 승인 가정값으로 분리한다.
- 날씨 모델은 풍속 중심의 단순 영향 또는 확장 기능으로 처리한다.
