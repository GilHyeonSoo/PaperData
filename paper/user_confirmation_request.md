# 사용자 컨펌 요청

AGENTS.md 지시에 따라 Python 구현 전 아래 항목의 승인이 필요합니다. 승인 전에는 `simulator/` 구현, 시뮬레이션 실행, 그래프 생성, 논문 초안 작성 단계로 넘어가지 않습니다.

## 0. 사용자 승인 결과
- 문헌 직접 근거가 없는 입력값은 “시뮬레이션 가정값”으로 승인됨.
- 속도 시나리오는 K-UAM 로드맵의 150/240/300 km/h를 사용하고, 시뮬레이터 내부에서는 m/s로 변환함.
- 기본 안전거리는 500 ft(약 152.4 m)로 사용하고, 30 m는 민감도 분석용 보조 시나리오로 사용함.
- 날씨 모델은 1차 구현에서 제외하고, 논문에는 확장 가능 기능으로만 서술함.
- 버티포트 수는 4/8/20 시나리오로 진행함.

## 1. 시뮬레이터 범위
| 항목 | 제안 | 출처/근거 | 사용자 승인 여부 |
|---|---|---|---|
| 맵 구현 범위 | 2D 격자 도시 + 2.5D 건물 높이 | 교수님 코멘트, K-UAM 로드맵 장애물/3D 지도 기술 방향 | 승인 |
| 건물 회피 구현 방식 | 직선 경로와 건물 footprint 교차 탐지 후 waypoint 우회 또는 고도 레이어 변경 | DPAM 논문, Panel Method 논문, 교수님 코멘트 | 승인 |
| 비행체 회피 구현 방식 | 우선순위 기반 출발 지연 + 고도 레이어 변경 | 국내 다중 UAV 무충돌 계획 논문, Pang et al. 2022 | 승인 |
| 날씨/풍속 반영 여부 | 1차 구현 제외, 논문에는 확장 가능 기능으로 서술 | 제주 UAM 기상 경로 논문 | 승인 |
| 버티포트 반영 여부 | 건물 옥상 또는 사용자 좌표 기반 출발지/목적지로 반영 | K-UAM 로드맵, 수도권 네트워크 연구 | 승인 |

## 6. 사용자에게 확인받아야 할 질문
1. 위 입력값 제안 중 문헌 직접 근거가 없는 값을 “시뮬레이션 가정값”으로 승인해도 될까요?
2. 속도 시나리오는 K-UAM 로드맵의 150/240/300 km/h를 사용할까요, 아니면 더 낮은 학부 실험용 값으로 단순화할까요?
3. 안전거리는 Yang & Wei 2021의 conflict 기준인 0.3 nmi(약 556 m), NMAC 기준인 500 ft(약 152 m), 또는 사용자 승인 가정값 30 m 중 어느 쪽을 기본값으로 둘까요?
4. 날씨 모델은 1차 구현에서 제외하고 논문에는 확장 가능 기능으로만 둘까요?
5. 버티포트 수는 로드맵·수도권 연구 기반의 4/8/20 시나리오로 둘까요, 아니면 단순 실험용 5개부터 시작할까요?
